# .github

Default community health files for the [metio](https://github.com/metio)
organization. GitHub applies each of these to every metio repository that does
not ship its own copy:

- [Code of Conduct](CODE_OF_CONDUCT.md)
- [Contributing guide](CONTRIBUTING.md)
- [Security policy](SECURITY.md)
- [Funding](FUNDING.yml) — the repository Sponsor button

A repository overrides any default by committing its own version of the file.
